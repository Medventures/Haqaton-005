# Инструкции для ИИ-агентов (Codex / GPT / Claude)

Проект: чат-бот подбора услуг клиники (хакатон). Бэкенд готов, фронтенд — `frontend/`.

## Перед любой работой над фронтендом прочитай

1. `DESIGN.md` — дизайн-правила. Они обязательны: цвета только из переменных, без градиентов, blur, эмодзи и больших теней.
2. `backend/openapi.yaml` — контракт API. Поля ответа не придумывать; если чего-то не хватает — написать владельцу бэкенда, а не менять `backend/`.

## Правила

- Стек фронтенда: React + Vite + TypeScript, иконки `lucide-react`, шрифт Inter (с `cyrillic-ext` — казахские буквы).
- Не трогать `backend/`, `catalog.json`, `triage_rules.json` в задачах по фронтенду.
- API в разработке: `docker compose up --build` → `http://localhost:8088`; в Vite проксировать `/api` туда.
- Коммиты маленькие и по смыслу (один компонент / одна страница), сообщения на английском в повелительном наклонении.
- Тексты интерфейса — ru и kk. Проверь отображение букв ә ғ қ ң ө ұ ү һ і.
- Проверяй на ширине 360px и на десктопе.
